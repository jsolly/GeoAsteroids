# Roid Tests

This folder contains browser integration tests for roid (asteroid) functionality.

## Test Files

- **roidSplitting.test.ts** - Tests roid splitting behavior when collided with

## Test Coverage

- Roid splitting mechanics
- Collision-based roid destruction
- Roid size progression (large → medium → small)
- Roid splitting point calculations
- Visual verification of roid splitting

## Dependencies

These tests use the browser test infrastructure:
- BrowserManager for browser automation
- GameInteractions for game control
